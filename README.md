# 오쌤

패션을 잘 모르는 초보자가 후회 없이 옷을 살 수 있게 돕는 폰 웹앱입니다.
상황과 원하는 느낌을 답하면, 어떤 옷을 왜 사야 하는지 추천하고 사는 방법까지 안내합니다.

- 상태: 기획 중 (v0.0)
- 대상: 남성복 먼저, 처음엔 혼자 사용 → 나중에 공개
- 사용: 폰 브라우저 (홈 화면에 추가하면 앱처럼 열림)

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `docs/` | 기획서, 결정 기록, 화면 시안 |
| `src/` | 앱 코드 (화면, 계산, 저장을 나눠서) |
| `data/` | 추천 자료 (상황, 느낌, 옷, 브랜드) |
| `tests/` | 자동 점검 |
